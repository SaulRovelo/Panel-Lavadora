## Tareas Realizadas:

### Botón de Temperatura

Se implementó un programa en C que controla la visualización de la temperatura mediante tres LEDs.
Se utilizó un botón para cambiar entre tres estados de temperatura.
Cada estado de temperatura corresponde a un LED encendido de manera secuencial.
Se estableció un ciclo para cambiar el estado de temperatura al presionar el botón.

### Programa: Botón de Ciclos de Lavado

Se desarrolló un programa en C para gestionar los ciclos de lavado mediante seis LEDs.
Se empleó un botón para alternar entre distintos modos de lavado, cada uno representado por un LED encendido.
Los modos de lavado incluyen: Normal, Lavado Rápido, Delicados, Ropa de Cama, Jeans y Lavado Eco de Tambor.
Se implementó un ciclo para cambiar entre los modos de lavado al presionar el botón.

### Botón de Tareas de Ciclos

Se creó un programa en C para controlar las tareas de los ciclos de lavado mediante tres LEDs.
Se utilizó un botón para contar las pulsaciones y cambiar el estado de los LEDs según el número de pulsaciones.
Los LEDs representan el estado de las tareas del ciclo de lavado, con distintas combinaciones según el número de pulsaciones.
Se estableció un mecanismo para reiniciar el contador de pulsaciones si el botón se mantiene presionado por más de dos segundos.

### Resultados y Conclusiones:
Se logró desarrollar tres programas funcionales en C para los diferentes botones para despues traducirlos a esamblador ARM
