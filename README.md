# Prender led 

Se realizó una prueba en lenguaje C para comprender el funcionamiento de un LED y cómo encenderlo.

# Boton encendido

Se completó con éxito la tarea relacionada con el botón de encendido. Esta función permite activar un LED al presionar el botón, simbolizando el encendido de la lavadora. Además, se implementó la funcionalidad para mostrar un mensaje en el monitor serial. Si el botón se vuelve a presionar, la lavadora se apaga, el LED se apaga y se muestra un mensaje correspondiente en el monitor serial. Este proceso fue desarrollado utilizando programas en lenguaje C y ARM.

# Boton Agua  en C

Se desarrolló un programa en lenguaje C para permitir al cliente seleccionar el nivel de agua deseado. Este programa funciona presionando el botón, lo que enciende el nivel 1. Al presionar nuevamente, pasa al siguiente nivel y así sucesivamente hasta alcanzar el nivel 5.
