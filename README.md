# Informe de Progreso: Eduardo
## Desarrollo e Implementación de Código para encender Un LED
### Encendido y Apagado de un LED
En el desarrollo reciente, se ha trabajado en la implementación de código para encender y apagar de un LED, alternando entre encendido y apagado cada segundo. Este proceso se realizó utilizando dos lenguajes de programación diferentes: C y ensamblador ARM.

### Implementación en Lenguaje C:
***10/04/2024***

Se desarrolló y codificó un programa en C destinado a encender y apagar un LED. El código permite encender el LED durante un segundo y luego apagarlo durante otro segundo, realizando esta acción de manera repetitiva.

### Implementación en Lenguaje de Ensamblaje ARM:
***12/04/2024***

Se creó una versión del programa en lenguaje de ensamblaje ARM, optimizada para su uso en la Raspberry Pi Pico W. Este código fue también diseñado para alternar el estado del LED cada segundo.

### Pruebas en Circuito Físico:

Ambas versiones del código fueron probadas en un circuito físico, donde se demostró la funcionalidad esperada. Los tests confirmaron que el LED se enciende y se apaga correctamente en los intervalos programados, validando así la efectividad de las implementaciones en ambos lenguajes.

### Implementacion de Display
***16/04/2024 - 17/04/2024***

Se implemento el display de 7 segmentos, su funcionamiento consiste en un contador decendente el cual simula el tiempo de trabaja de la lavadora, el cual se puede controlar con un boton (inicio/pausa), y al llegar a cero (0) se imprime un mensaje en pantalla dando a entender que la lavadora ha finalizado su decion de lavado.
