
# Boton encendido

Se completó la tarea del botón de encendido, la cual consiste en presionar el botón para encender la lavadora (activando un LED) y mostrar un mensaje en el monitor serial. Si se vuelve a presionar el botón, se apaga la lavadora (apagando el LED) y se muestra un mensaje en el monitor serial. Este proceso cuenta con programas en C y ARM.
